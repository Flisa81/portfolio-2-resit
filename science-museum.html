Community Science Museum

View live site View GitHub README

Overview

This project is an accessible and responsive website for a community science museum. It presents exhibitions, events, visitor information, and educational content in a clear structure for families and young visitors.

Key features

  • Responsive page layout
  • Exhibit and event pages
  • Improved calendar styling
  • Accessible navigation and semantic HTML

Improvements made

I improved the layout, reduced oversized sections, added hover states, refined exhibit cards, improved the calendar, and made the site feel more polished and professional.

What I learned

This project helped me improve my understanding of semantic HTML, accessibility, responsive design, and visual hierarchy.

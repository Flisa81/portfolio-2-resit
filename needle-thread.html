Felicia's Needle & Thread

View live site View GitHub README

Overview

Felicia's Needle & Thread is a sewing-inspired blog platform based on one of my personal hobbies. Users can register, log in, view a feed, create posts, and interact with API-based content.

Key features

  • User login and register flow
  • Feed page with images
  • Create post functionality
  • API integration and persistent login state

Improvements made

I fixed authentication issues, improved the feed, added fallback images, improved the header and contact page, fixed post page bugs, and made the design more consistent with the sewing theme.

What I learned

This project taught me a lot about API debugging, authentication, localStorage, error handling, and how small bugs can affect the full user experience.

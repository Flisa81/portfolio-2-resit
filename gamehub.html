GameHub

Overview

GameHub is an e-commerce style website where users can browse games, view product information, add games to a cart, and complete a checkout flow.

Key features

  • Game product cards
  • Cart and checkout flow
  • Responsive product layout
  • Improved homepage design

Improvements made

I improved the homepage design, made the product cards more inviting, added stronger hover feedback, and fixed checkout issues so the user flow feels more reliable.

What I learned

This project strengthened my JavaScript skills and helped me better understand cart logic, user feedback, layout polish, and interactive user experiences.
